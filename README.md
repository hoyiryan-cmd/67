# 學習回聲

繁體中文匿名課程回饋應用，使用 Python 3.10+ 標準函式庫和 SQLite，無須安裝額外套件。

## 本機啟動

```sh
cd /workspace/67
python3 app.py
```

預設只監聽本機 8000 埠。`HOST`、`PORT` 可指定監聽位址及埠，`FEEDBACK_DB` 可指定資料庫路徑。資料庫預設位於 `data/feedback.db`。

```sh
python3 -m unittest discover -s tests -v
```

## 公開部署（Render）

1. 將本專案提交並推送至你的 GitHub 儲存庫。
2. 在 Render 建立 Blueprint，連接該儲存庫，使用根目錄的 `render.yaml`。
3. 設定含持久磁碟的方案，確認平台顯示的費用後部署。此設定使用付費 Starter 和 1GB 磁碟，避免服務重啟遺失回饋。
4. 部署完成後，開啟 Render 提供的 HTTPS 網址。健康檢查為 `/health`。

公開部署需要 Render 帳號、儲存庫授權與平台確認；此檔案本身不會建立服務或網址。請使用單一服務實例，定期備份 SQLite 資料庫。

## 功能與限制

- 五項必填評分及選填建議，成功後重新導向，避免重新整理重送。
- 各課程達五份才呈現平均、關鍵詞主題與彙整 CSV；不公開原始留言。
- 常見電話、電子郵件和識別資訊檢查，不保證能辨識所有個資。
- 不收集姓名或學號；主機供應商仍可能保留網路存取紀錄。
- 公開摘要無登入限制；尚無防重複填答或機器人防護。此版本適合試用，正式校務使用前需另外設定存取權限、保存期限與濫用防護。
